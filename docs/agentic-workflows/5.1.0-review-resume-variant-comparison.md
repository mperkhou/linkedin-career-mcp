# 5.1.0 Implementation Plan Stub: Review Resume Variant Comparison

Status: planning stub only; expand after `5.0.0` is accepted and tagged

This stub reserves `5.1.0` for a non-breaking Review-page improvement. It is
not implementation authority and does not alter the accepted `5.0.0`
workspace-separation plan.

## Recommended Scope

Add two explicit comparison selectors to the Flask Review page. Each selector
should offer the resume variants that exist for the application, including
`v1`, `v2`, and `manual`, so the rendered diff can switch among at least:

- `v1` versus `v2`;
- `v2` versus `manual`; and
- `v1` versus `manual`.

Changing the comparison pair must update only the displayed diff. It must not
change the stored selected resume variant, rewrite any variant, alter
highlighting, or disturb variant lineage.

The detailed plan should inspect the existing Review route, template,
JavaScript, diff rendering, and tests before choosing the final control and
state design. Prefer the existing DB-backed variant records and avoid a schema
change unless implementation evidence demonstrates that one is necessary.

## Release Boundary

Begin detailed planning only after `5.0.0` completes its operational cutover,
user soak, explicit acceptance, and tag. Execute `5.1.0` through the active
`agentic-feature-workflow`, including independent gates, Flask/browser
validation, clean-main cutover, user acceptance, and acceptance-before-tag.

The remaining public-rebuild migration is deliberately deferred intact to the
[5.2.0 rolling roadmap](5.2.0-public-rebuild-roadmap.md).
