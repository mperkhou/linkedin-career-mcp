# 4.1.1 Release Notes: Embedded Job-Page Extraction

Version 4.1.1 expands the generic Other URL scraper for embedded application
payloads.

## Why This Release Exists

Some job pages render an app shell while storing the real posting data in
embedded payloads. The tracker needed to read those payloads instead of failing
with unusable visible text.

## What Changed

- Added parsing for Dayforce-style Next.js `__NEXT_DATA__` job payloads.
- Added parsing for Work at a Startup-style Inertia `data-page` payloads.
- Preserved schema.org `JobPosting` metadata as the highest-priority source.
- Added parser coverage for both embedded app-shell formats.
- Bumped the package version to `4.1.1`.
