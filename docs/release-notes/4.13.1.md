# 4.13.1 - Reserve 5.1.0 for resume comparison

Version 4.13.1 records the next two planned `5.x` releases without beginning
their implementation.

The new `5.1.0` stub reserves that release for a Flask Review-page improvement
with two explicit resume-version selectors. The intended comparisons include
`v1` versus `v2`, `v2` versus `manual`, and `v1` versus `manual`; switching the
displayed pair must not change the application's stored selected variant.

The existing public-rebuild roadmap moves intact to `5.2.0`. The `5.0.0`
workspace-separation plan now hands off first to the Review-page feature, while
synthetic substitution, documentation rebuilding, privacy review, public
repository creation, cutover, and renaming remain deferred.

This patch changes planning documentation and its contract tests only. It does
not change Flask behavior, tracker data, resume variants, workspace handling,
or the accepted `5.0.0` implementation scope.
