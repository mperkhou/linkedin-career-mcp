# 4.8.0 Release Notes: Older Professional Experience Rendering

Version 4.8.0 renders Stamats Communications and VIDA Diagnostics as visible
older professional experience in generated resumes.

## Why

Generated resumes already claimed 10+ years of relevant professional
experience, but the visible timeline stopped at the newer Oracle, University of
Iowa, and Steindler roles. Stamats and VIDA carry older infrastructure,
automation, security, data-transfer, and healthcare-platform evidence that
better supports that summary claim when the roles are rendered.

## What Changed

- Enabled Stamats Communications and VIDA Diagnostics in the MRO professional
  experience render settings.
- Matched the existing rendered non-Oracle bullet policy used by University of
  Iowa and Steindler: two to five generated bullets per role.
- Kept source bullets hidden in the direct MRO render while allowing the v1
  job-aware rewrite workflow to produce rendered bullets for generated resumes.
- Added a committed agentic workflow plan for the 4.8.0 dogfood run.
- Added regression coverage for role inclusion, render settings, and v1
  timeout/retry propagation across rendered non-Oracle roles.

## Operational Notes

This release does not mutate tracker rows or stored generated resume artifacts.
Regenerate selected resumes explicitly when you want existing application rows
to pick up the expanded timeline.
