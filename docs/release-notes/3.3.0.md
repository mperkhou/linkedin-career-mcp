# 3.3.0 Release Notes: Job-Aware Experience Bullet Rewriting

Version 3.3.0 improves the prompt used to rewrite experience bullets for each
job.

## Why This Release Exists

The earlier rewrite prompt was too literal and too tied to a single formatting
style. Senior platform roles need evidence-backed bullets that can vary action
verbs, sentence shape, production-pressure framing, and operational judgment
without inventing unsupported experience.

## What Changed

- Replaced the literal Google XYZ rewrite instruction with a job-aware senior
  resume editing prompt.
- Tuned the rewrite prompt to surface supported architecture, reliability,
  security, observability, and operational evidence.
- Capped rendered matched Core Technical Skills additions per category while
  preserving full match context in the ARO.
- Bumped the package version to `3.3.0`.

## Validation

This note was backfilled in 4.4.0 from the changelog entry so release-note
coverage is complete for post-3.0.0 releases.
