# 4.7.1 Release Notes: Link Agentic Workflow Controller by Default

Version 4.7.1 makes the 4.7.0 agentic workflow controller part of the default
local skill-link setup.

## Why

The controller skill was added in 4.7.0, but `make install` and `make
skill-link` only linked the older default skill set unless callers explicitly
set `SKILL_NAME=agentic-workflow-controller`. That made the skill less likely to
be auto-discovered in fresh Codex sessions.

## What Changed

- Added `agentic-workflow-controller` to the default `SKILL_NAMES` list in the
  Makefile.
- Added a Makefile regression test so the default skill-link dry run includes
  the controller while still honoring `SKILL_NAME` overrides.

## Operational Notes

Run `make skill-link` after updating to refresh local symlinks under
`~/.codex/skills`. Fresh `make install` runs now link the controller by default.
