# 4.0.2 Release Notes: Codex Workflow Reasoning Effort

Version 4.0.2 pins Codex reasoning effort for resume manual pass and
highlighting workflows and extends add-popup chaining.

## Why This Release Exists

Codex-powered resume workflows should not depend on whatever reasoning effort is
configured globally for the caller. The tracker add flow also needed to chain v2
refinement and highlighting predictably.

## What Changed

- Added `CODEX_REASONING_EFFORT`, defaulting to `xhigh`, for Codex manual pass
  and selected-resume highlighting.
- Passed `model_reasoning_effort` explicitly to `codex exec`.
- Stored the Codex reasoning effort in manual-pass metadata.
- Added `Run v2 refinement` controls to the Add popup for LinkedIn and Other URL
  forms.
- Increased the default v2 refinement LLM timeout from 300 to 600 seconds.
- Bumped the package version to `4.0.2`.

## Validation

This note was backfilled in 4.4.0 from the changelog entry so release-note
coverage is complete for post-3.0.0 releases.
