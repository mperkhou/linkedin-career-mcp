# 3.4.0 Release Notes: Codex Resume Highlighting Workflow

Version 3.4.0 adds a guarded Codex polish step for selective resume emphasis.

## Why This Release Exists

Generated resumes sometimes need visual emphasis, but highlighting must not
change wording or introduce unsupported markup. The workflow treats Codex as a
post-generation reviewer that can propose emphasis while preserving the resume
content.

## What Changed

- Added guarded Codex JSON-patch highlighting for professional-experience
  bullets.
- Added `make highlight-draft-resumes`, a Flask tracker batch action, and an
  add-job checkbox for chained highlighting after draft generation.
- Added controls to limit highlighting to a specific rendered company or ARO job
  order.
- Documented the design decision in ADR 0002.
- Bumped the package version to `3.4.0`.
