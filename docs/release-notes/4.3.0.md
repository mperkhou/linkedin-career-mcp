# 4.3.0 Release Notes: Canonical Agent Guidance

Version 4.3.0 adds root `AGENTS.md` as the canonical operating guide for agents
working in this repository.

## Why This Release Exists

The project depends on agent-assisted work in several places: repository
implementation, release closeout, tracker diagnostics, Codex manual resume pass,
Codex resume highlighting, and evidence-grounded application writing. Before
4.3.0, shared guardrails for that work were spread across README text, skill
instructions, changelog entries, and prior workflow memory.

That split made guidance easier to miss. The same repo-level rules need to
apply whether an agent is editing Python, reviewing a generated resume, writing
application prose, or closing out a release.

## What Changed

- Added root `AGENTS.md` as the canonical repo-level guidance file for agents.
- Centralized edit safety, canonical state, tracker workflow invariants,
  release closeout, long-running workflow visibility, and resume-evidence
  discipline.
- Linked README and the repo skills to `AGENTS.md` while keeping human-facing
  docs and command-specific skill docs concise.
- Added tests that assert `AGENTS.md` exists and includes required release
  closeout language for annotated tags, tag pushes, and remote tag verification.

## Guidance Model

`AGENTS.md` is the operational guardrail layer.

`README.md` remains the product and operator guide.

`skills/linkedin-career-mcp/SKILL.md` remains the command-level workflow
reference for the local MCP server, Make targets, and tracker workflows.

`skills/manual-resume-passthrough/SKILL.md` remains the focused protocol for
grounded manual resume pass work.

Shared rules should move into `AGENTS.md` when they apply across multiple agent
workflows. Workflow-specific instructions should stay in the relevant skill or
architecture document and link back to `AGENTS.md` when needed.

## Validation

The release added regression coverage for the canonical guidance file and its
release closeout requirements. Follow-up docs in 4.3.1 expand the architecture
notes and ADR trail around this design.
