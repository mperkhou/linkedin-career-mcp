# 4.1.0 Release Notes: V1 Draft Timeouts and Progress Logging

Version 4.1.0 makes first-draft resume generation more observable and less able
to hang indefinitely.

## Why This Release Exists

V1 generation can involve multiple LLM calls per job. A single slow provider
response should not freeze the whole workflow without useful status output.

## What Changed

- Added `FIRST_DRAFT_LLM_TIMEOUT_SECONDS`, defaulting to 300 seconds.
- Wrapped each v1 LLM substep with a hard wall-clock timeout.
- Logged first-draft substep start, completion, elapsed seconds, timeout
  failures, and job ID to stderr.
- Kept stdout JSON stable for script consumers while improving Flask tracker
  status visibility.
- Bumped the package version to `4.1.0`.
