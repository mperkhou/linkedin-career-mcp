# 3.5.0 Release Notes: Manual Resume Passthrough Workflow

Version 3.5.0 adds the reusable Codex manual resume passthrough workflow.

## Why This Release Exists

Some tailored resumes benefit from a grounded manual second pass after the
automated generation workflow. That process needed a reusable skill and tracker
signals so future sessions could apply it consistently.

## What Changed

- Opened tracker `Job URL` links directly to stored LinkedIn postings in a new
  tab instead of routing through the local helper page.
- Added a `Manual pass` badge for applications whose notes record a manual
  second-pass refresh.
- Added the project Codex skill for the grounded manual resume passthrough
  workflow and linked it through default skill setup.
- Bumped the package version to `3.5.0`.

## Validation

This note was backfilled in 4.4.0 from the changelog entry so release-note
coverage is complete for post-3.0.0 releases.
