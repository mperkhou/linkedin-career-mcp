# 4.12.1 - Preserve manual-pass skill taxonomy

Version 4.12.1 keeps the Codex manual resume pass grounded in the stored v2
skill structure. It also refreshes the canonical master-resume evidence for
recent agentic-delivery and repository-workflow work without changing tracker
data, database schemas, or workflow commands.

## Manual-Pass Behavior

The manual pass now inherits the complete `core_technical_skills` section from
the stored v2 Application Resume Object, including category names, category
order, skill inventories, and display values. Codex may still revise the
manual variant's prose and per-category `jod_matched_items`, but it cannot
replace the v2 taxonomy with a newly generated one.

The renderer now resolves JOD matches against exact displayed skill values
before consulting aliases. This preserves canonical labels and avoids
duplicate or substituted rendering when an alias overlaps a displayed item.

## Master-Resume Evidence

The canonical YAML and text master-resume sources now include the latest
grounded Oracle PDAF agentic-delivery work, composable Jira and repository
workflow controls, GitHub Enterprise and Jenkins delivery evidence, and the
Career Agent Workbench portfolio and GitHub Actions CI description. Existing
distinct evidence was retained while superseded wording was consolidated.

## Compatibility

No database migration is required. Existing v1, v2, and manual variants remain
unchanged until the manual pass is rerun. The release does not change model,
timeout, retry, command, or tracker-selection configuration.
