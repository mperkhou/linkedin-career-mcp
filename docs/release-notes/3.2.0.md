# 3.2.0 Release Notes: Core Technical Skills Matching

Version 3.2.0 tunes the ARO matching and resume rendering path around Core
Technical Skills.

## Why This Release Exists

The resume generator needed richer matching aliases without letting helper
phrases leak into rendered skills. It also needed safer ARO refresh behavior and
more stable two-page PDF output.

## What Changed

- Added non-display `match_terms` aliases to the master resume skill inventory.
- Canonicalized helper matches back to display skills before storing ARO
  matches.
- De-duplicated rendered Core Technical Skills globally.
- Tightened the master skill inventory so process phrases remain matching
  context instead of rendered skills.
- Preserved job-specific bullets and attached JOD context during ARO refreshes.
- Restored readable two-page PDF rendering and linked the portfolio workflow
  note to the GitHub repository.
- Bumped the package version to `3.2.0`.

## Validation

This note was backfilled in 4.4.0 from the changelog entry so release-note
coverage is complete for post-3.0.0 releases.
