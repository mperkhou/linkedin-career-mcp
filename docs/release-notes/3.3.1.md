# 3.3.1 Release Notes: Education Section Resume Layout

Version 3.3.1 polishes the rendered Education section.

## Why This Release Exists

Education entries should use the same readable hierarchy as Professional
Experience. The prior layout made institutions feel nested behind bullets,
which weakened scanability.

## What Changed

- Rendered Education entries with the same heading-and-bullet hierarchy used by
  Professional Experience.
- Kept education details on standard filled bullets.
- Bumped the package version to `3.3.1`.

## Validation

This note was backfilled in 4.4.0 from the changelog entry so release-note
coverage is complete for post-3.0.0 releases.
