# 3.1.0 Release Notes: Flask Tracker Archiving

Version 3.1.0 adds a non-destructive archive workflow to the Flask tracker.

## Why This Release Exists

The tracker database is useful as development history as well as application
state. Stale postings should not clutter the default active view, but deleting
rows would throw away generated artifacts, diagnostics, and workflow examples.

## What Changed

- Added an archive state for application rows.
- Added batch Archive and Restore controls.
- Added Active, Archived, and All views that preserve search, status, and sort
  state.
- Bumped the package version to `3.1.0` for the tracker feature.
