# 4.2.0 Release Notes: Batch URL Loading and Chained Manual Workflows

Version 4.2.0 adds batch URL loading and richer chained resume workflows in the
tracker.

## Why This Release Exists

The Add popup needed to handle multiple LinkedIn or generic job URLs at once and
then run the desired generation stages in order. Manual pass and highlighting
also needed deterministic chaining around the correct resume variant.

## What Changed

- Let LinkedIn and Other URL forms accept comma- or newline-separated URL
  batches.
- Collected per-URL failures while starting resume workflows for successful
  rows.
- Added `Run Codex manual pass` controls that require v2 refinement.
- Chained v1, v2, manual pass, and highlighting in ordered background actions.
- Targeted `v2` after v2 refinement and `manual` after a chained manual pass.
- Added a combined Actions-menu option for v1 plus v2 plus manual pass.
- Bumped the package version to `4.2.0`.
