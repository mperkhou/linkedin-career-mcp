# 4.10.1 - Remove resume automation disclaimer

Version 4.10.1 is a narrow resume-content and presentation patch. It removes
the automated-tailoring disclaimer from the canonical master-resume text and
MRO so newly generated resumes no longer present the submitted resume as
automatically tailored.

The LinkedIn Career MCP portfolio entry remains in place with the existing
GitHub URL. Its description now emphasizes the project's local-first Python
and MCP platform, SQLite-backed state, versioned artifacts, retryable batch
processing, ATS diagnostics, human review gates, and agentic workflow
controls.

The renderer retains generic `summary_note` support and normal HTTP/HTTPS
linkification. The disclaimer-specific bare `mperkhou/linkedin-career-mcp`
linkification special case is removed because the disclaimer no longer exists.

Validation and migration notes:

- Existing tracker rows and stored DB-backed `v1`, `v2`, and `manual` resume
  variants remain unchanged until explicitly regenerated.
- This release does not mutate `output/tracking/applications.sqlite3`,
  generated resume HTML/PDF files, or application records.
