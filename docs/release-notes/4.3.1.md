# 4.3.1 Release Notes: Document Canonical Agent Guidance

Version 4.3.1 expands documentation around the `AGENTS.md` guidance model.

## Why This Release Exists

After adding `AGENTS.md`, the README, architecture docs, ADR trail, and tests
needed to describe how the guidance layer fits with human-facing documentation
and skill-specific command references.

## What Changed

- Expanded README and architecture docs to describe `AGENTS.md` as the canonical
  operational guardrail layer.
- Added ADR 0005 and 4.3.0 release notes explaining why shared agent guidance
  lives in `AGENTS.md`.
- Extended regression coverage so README, architecture docs, ADRs, and release
  notes stay linked to the AGENTS implementation.
- Bumped the package version to `4.3.1`.

## Validation

This note was backfilled in 4.4.0 from the changelog entry so release-note
coverage is complete for post-3.0.0 releases.
