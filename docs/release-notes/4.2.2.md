# 4.2.2 Release Notes: Required Release Tags

Version 4.2.2 records release closeout as incomplete until the matching remote
tag exists.

## Why This Release Exists

PR merges alone were not enough to make GitHub releases and local release
metadata line up. The repo needed a stronger operational rule that every merged
release ends with a pushed, verified tag.

## What Changed

- Documented remote release tag creation as mandatory after PR merge.
- Required annotated tag creation on synced `main`.
- Required pushing `vX.Y.Z` to `origin` and verifying the remote ref with
  `git ls-remote --tags origin refs/tags/vX.Y.Z`.
- Bumped the package version to `4.2.2`.

## Validation

This note was backfilled in 4.4.0 from the changelog entry so release-note
coverage is complete for post-3.0.0 releases.
