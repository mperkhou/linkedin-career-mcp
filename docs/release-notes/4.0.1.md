# 4.0.1 Release Notes: Legacy Manual Variant Backfill

Version 4.0.1 migrates legacy manual pass work into the DB-backed resume variant
model introduced in 4.0.0.

## Why This Release Exists

Older Codex manual-pass edits existed outside the new `manual` resume variant
flow. The tracker needed to surface those historical manual passes while keeping
variant selection reversible and explicit.

## What Changed

- Backfilled legacy manual edits into the `manual` resume variant.
- Defaulted automatic tracker selection to `manual > v2 > v1` while preserving
  explicit Review-page selections.
- Showed all available resume variant badges in the tracker Job column.
- Fixed highlighting so it reads and updates the selected variant instead of
  assuming `v1`.
- Updated tracker and workflow wording around selected-resume highlighting.
- Bumped the package version to `4.0.1`.

## Validation

This note was backfilled in 4.4.0 from the changelog entry so release-note
coverage is complete for post-3.0.0 releases.
